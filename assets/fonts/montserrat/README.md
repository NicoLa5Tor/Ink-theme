# Montserrat (self-hosted)

Colocar aquí los archivos `.woff2` referenciados en `src/styles/app.css`:

- `montserrat-600.woff2` (SemiBold, para subtítulos)
- `montserrat-800.woff2` (ExtraBold, para H1/H2)

Descargar desde [Google Fonts](https://fonts.google.com/specimen/Montserrat) y convertir a woff2
(subset `latin` es suficiente para el mercado colombiano) antes de commitear.
