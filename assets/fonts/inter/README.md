# Inter (self-hosted)

Colocar aquí los archivos `.woff2` referenciados en `src/styles/app.css`:

- `inter-400.woff2` (Regular, texto de cuerpo)
- `inter-600.woff2` (SemiBold, énfasis y labels)

Descargar desde [Google Fonts](https://fonts.google.com/specimen/Inter) y convertir a woff2
(subset `latin`) antes de commitear.
